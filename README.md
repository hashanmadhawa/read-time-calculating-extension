# read-time-calculating-extension
# Reading Time Web Extension

A simple Chrome web extension that estimates the time required to read the current web page.

## Features
* Calculates the approximate reading time based on the number of words.

## Files

* `manifest.json` – Contains the extension configuration and permissions.
* `content.js` – Extracts the page content and calculates the estimated reading time.

## How to Use

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.
6. Open any web page to use the extension.

## Technologies

* HTML
* JavaScript
* Chrome Extensions API

## Purpose

This project was created to learn the basics of developing Chrome extensions and working with web page content using JavaScript.
